# Privacy and external connections

Version 2026-09-07.1 · Draft for review

Projects, imagery, analysis results and processing records are stored in folders you choose.
Recent project paths, workspace preferences, update status and a local record of accepted terms
are stored in the existing StrataScope state folder (normally LocalAppData/Stallite).
Uninstalling the application preserves these files. You can remove them yourself after backing
up anything you need. Earthdata credentials use the operating system credential store.

StrataScope does not upload your project files or run background usage analytics. Requests you
make to satellite archives include the search area, dates and filters needed for that service.
Online maps receive tile requests identifying the viewed area; location searches send the text
you enter. Authenticated services receive the credentials required for those requests.

Update checks contact GitHub for public release metadata. Downloads contact GitHub and its delivery
services. These providers receive normal connection information such as your IP address, request
time and client headers. Their own privacy policies and international hosting arrangements apply.
No account token for publishing updates is included in the application. Online map providers,
NASA Earthdata/CMR, Microsoft Planetary Computer and other selected data services operate separately
from MSONICOP. Source labels identify the service used.

Local update diagnostics record status, versions and error categories, without imagery, credentials
or study boundaries. Logs rotate at bounded sizes. Exporting diagnostics creates a local file for
you to inspect and choose whether to share; the application does not send it automatically.

Saved studies, imported data and bundled offline maps work without internet access. New online
imagery, online maps and update checks need a connection. Notify only prevents automatic update
downloads but still permits periodic metadata checks. You can disable scheduled update checks.

If you email support, MSONICOP receives what you choose to send. Send only relevant information and
remove sensitive project content. Support correspondence retention and formal POPIA procedures
must be confirmed during the publisher's legal/privacy review before public distribution.
