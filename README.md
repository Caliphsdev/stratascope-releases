# StrataScope

Satellite imagery, geological reconnaissance and professional map/report creation for Windows.

**Owner and publisher:** MSONICOP, South Africa.

© 2026 MSONICOP.

StrataScope helps geologists choose a study area, find or import imagery, review image quality,
explore surface signatures and create reproducible maps and reports. It supports Sentinel-2 and
Landsat workflows, reviewed ASTER inputs, spectral analysis and SRTM terrain mapping. Intermediate
results can be reviewed before continuing. A4/A3 layouts and readable reports retain author credits.

This repository contains **approved installers, release notes, legal notices and third-party sources**.
MSONICOP's proprietary application source stays in a separate private repository.

## Availability

The 0.2.0 candidate is under testing and legal/licensing review. No public release is approved yet.
When approved, install from Releases; existing 0.1.x users should choose the Migration installer.
Configured installed copies receive verified updates through Settings → Updates. Choose Automatic
or Notify only. Installation waits for safe exit and does not interrupt active processing.

Free pilot use includes professional/client work under the application terms. Surface evidence
does not prove deposits, grades, reserves or economic viability. Independent professional assessment
and field/laboratory verification are required. Some published workflows remain locked pending validation.

Saved studies, imported imagery, local libraries and offline maps work offline. Online searches,
downloads and online tiles need a connection. Windows Settings → Apps removes the app while preserving studies.
